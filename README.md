# CSM-C Attendance Assistant

iPhone-friendly attendance PWA for the II-I CSM-C class.

## Data
- Regular: 65 roll numbers
- LE: 6 roll numbers
- Names are intentionally not stored.
- CSM-D is not included.

## Features
- Date and subject
- CSM-C / LE switch
- Tap roll numbers to mark absent
- Automatic present/absent/percentage
- WhatsApp-ready message
- Copy and Share buttons
- Saves attendance locally on the device
- Offline PWA caching
- iPhone Add to Home Screen support

## GitHub Pages
Upload all files to a GitHub repository. In Settings → Pages, select Deploy from a branch → main → /root.

Open the Pages URL in Safari. Tap Share → Add to Home Screen.

## Important
This is a client-side attendance utility. It does not require Firebase or a server for the basic workflow. Attendance is stored in the browser's local storage on the device.
